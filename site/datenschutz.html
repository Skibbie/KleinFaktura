Das Programm KleinFaktura

KleinFaktura speichert alle Daten (Kunden, Belege, Ausgaben, Fahrten) ausschließlich lokal auf dem eigenen PC. Es gibt kein Benutzerkonto und keine Übertragung dieser Daten an den Herausgeber.

Für die Suche nach Updates fragt das Programm beim Start die öffentliche Schnittstelle von GitHub (api.github.com) nach der neuesten Version; dabei werden die IP-Adresse und die Programmversion an GitHub übermittelt. Die Suche lässt sich unter Einstellungen → Programm-Updates abschalten. Der Knopf „Route anzeigen“ bei Fahrten öffnet auf Wunsch Google Maps im Browser.
